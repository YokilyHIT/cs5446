# GPU 与队友研究路线：一致点、差异和待定事项

更新：2026-10-15。对照仓库中的 [10 月 12 日 ReAct 路线](../../ReAct研究路线与实验计划_20261012_090343.md) 与 GPU 侧当前研究协议。本页用于团队讨论，不替团队批准新实验或研究范围调整。

## 总体判断

**核心问题一致，但两份计划不能直接当作同一套执行协议。** 双方都固定 ReAct 与一步 WM，区分预测准确性和决策效用，重视无预测再思考对照、逐游戏配对、失败与成本，并主张先检查效用变化再考虑学习 gate。

10 月 12 日路线尚未包含 GPU 侧于 10 月 15 日完成的 D0-var：24 游戏、71 预选点，68 点有三分支有效结果，3 点源 draft 失败。局部终局差异极稀疏；该结果是开发期单次续跑描述，不是 confidence 无效或整局 Always 无效的证明。

## 需要统一的差异

| 项目 | 队友路线 | GPU 当前协议及建议 |
|---|---|---|
| Gate 的时点 | 优先考虑调用 WM **之前**判断是否值得调用 | Proposal 的条件性 Utility Gate 在预测生成**之后**决定是否接纳，可用 confidence/预测特征；拒绝仍已支付 WM 成本。调用前 gate 是另一项研究扩展，不能直接沿用后置门控结论 |
| 局部对照 | 诊断段写 D/P 两分支 | 保留 **D/N/P**，分别报告 P−D、P−N、N−D。只有 P−D 无法分离预测信息与再次决策 |
| 在线基线 | None、no-info、Always、Random、Confidence 五组 | 当前必做整局比较为 **None/no_info/Always**，主差 Always−no_info；A 中 Random 是同覆盖率解析参照。额外在线两臂需要另定范围 |
| 选点 | 约 200 个状态，重点覆盖停滞和困难情况 | 已完成 D0 固定 24 游戏、按哈希每游戏最多 3 点。不能重新挑难例替换或混入；定向诊断须另标范围 |
| unseen 清单 | 引用 134 任务口径 | GPU 盘点有 255 个定义，资格仍待核实，**不是 255 个已合格样本**。先核 ID、内容、使用历史与资产，确定共同 E 清单；不能只比较数量 |
| 重复与扩展 | best-of-1…5、后续第二模型 | 单次 SR@30 仍为当前主口径。这些可列后续扩展，不自动增加实验量 |

“WM 调用前 gate”不能读取尚未生成的预测或 logprob；“预测后接纳”可以使用它们，但不能声称省下该次 WM 调用。两种方案的特征、决策位置和成本解释必须分开。

## 现在如何合并推进

1. 用当前 D0 数据完成 confidence—准确性—观测效用、分层、案例与成本描述，并完成既定 N/P 有界抽查。不因旧路线尚列“采 200 点”而重跑 D0。
2. 共同准备 E 上 None/no_info/Always 的清单、固定样本量、顺序和配对分析。GPU/NPU 数据按部署分别记录，不能因为同用 Qwen3-4B 和 ReAct 就直接合池。
3. 当前建议预算优先核心 B、暂不启动大规模 D1；**把 A 从确认性 D1 改为 D0 探索性诊断仍是团队待定事项**。若采用，应在验证结果可见前写明修订和交付限制。
4. 调用前 gate、额外线上基线、难例补采、best-of-5 和第二模型暂列可选扩展，不作为完成当前核心的前置。

需要队友补充：NPU 实验的 game ID/内容哈希与历史使用用途（包括 memory bank、action-state、阈值校准），以及实际 profile、提示词/解析、token/history 上限、失败规则、环境和后端配置。140 个 seen 游戏的旧汇总可以作为历史开发证据；未恢复逐游戏原件前，不能据总成功数构造配对检验。

## 解释边界

算力分工建议：GPU 侧维护已采集 D0、必要 N/P 复测和研究协议；有稳定 NPU 资源的成员优先完成核心 B，再考虑方法扩展。若 E 由 NPU 主跑，应在查看 E 结果前明确该部署修订，三臂在同一 NPU 配置内配对；不要求把 GPU 的所有历史执行包装层移植过去，也不直接合并 GPU/NPU 结果。此处是待团队落实的安排，不表示 E 已获准运行。

- 少量局部非零不证明真实条件效用为零，也不证明差异被后续 μ 因果性地“抹平”。
- N 的策略格式失败按原定义为 Y=0；由此形成的 P−N 正差仍保留，并说明来源，不能事后删掉。
- 现有数据不支持直接训练一个可靠 Utility Gate。核心 B 也不保证产生显著提升。
- 本次只对照团队协议与本地证据，没有重新核查队友文档里的论文数字或执行其建议实验。
