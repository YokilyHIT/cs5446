# 当前研究协议：局部效用与整局三臂

更新：2026-10-15。本页是便携的研究定义摘要，不是新实验执行授权。现有结果及缺测解释见[数据说明](../data/README.md)，团队路线差异见[路线对照](ROUTE_ALIGNMENT.md)。

## 固定研究对象

固定 ALFWorld 文本环境、Qwen3-4B-Instruct-2507 Planner 与一步 WM、单调用 ReAct 决策、无记忆和 30 次真实动作上限。已采 GPU 配置为 `react_single_env_action_v1`、seed 42、temperature 0、top_p 0.5、Planner/WM 输出上限 384/256、history 50。

当前 GPU 采集使用整卡 A100-PCIE-40GB。相同模型名和 ReAct 名称不保证相同策略或后端行为；模型、提示词、解析、预算、环境和失败规则均需对齐。若 NPU 主跑 E，应在查看 E 结果前共同确认部署修订，三臂在固定 NPU 配置内配对，GPU/NPU 结果分别报告。

## 核心 A：同状态 D/N/P 局部测量

从固定 None 策略访问的未终止状态预选决策点；恢复同一环境、历史和剩余预算。WM 预测的是原 draft 动作的下一步 observation。

| 分支 | 当前步干预 |
|---|---|
| D | 执行源轨迹中已审计的 draft 动作 |
| N | 不提供预测，再决策一次 |
| P | 提供 WM 预测后，再决策一次 |

只干预当前步，之后均使用同一无预测策略 μ 续跑。已执行 t 步时，剩余总预算为 30−t，包含干预动作。D0-var 的每个物理组为 r=1；首动作精确相同且在可见菜单内时才按冻结规则共享续跑。

令 V 为固定条件下的期望终局结果，Y 为一次实际观测：

- 接纳效用：`U_admission = V_P − V_D`。
- 信息效用：`U_info = V_P − V_N`。
- 再决策效用：`U_revision = V_N − V_D`。
- `U_admission = U_info + U_revision`；一次 Y 差不能当成已知真实 U。

原 A 验证计划在独立 D1 上比较 confidence 前 50% 权重与同覆盖率的解析 Random；无需新增在线 Random 臂。局部排序诊断不等于可部署 gate 的整局收益。

## 权重、失败与预测准确性

- 每游戏先等权，游戏内按原预选点数 k_j 等权：`1/(J*k_j)`。D0 的 J=24。分析子集保留原权重，再在相应资格集合整体归一，不按删点后的每局剩余点数重新平权。
- 源 draft 失败尚未形成局部预测事件：保留原计划点和失败分母，局部 Y、confidence、accuracy、U 为缺失，不补点或补零。
- 已审计的分支策略内容/格式失败按原定义计 `Y=0`。N 首动作缺失仍可形成有效终局失败，只在需要可执行动作的比较中排除。
- 技术、采集、恢复或证据契约问题单列缺测/资格待审；尚未运行单列，不能覆盖已经观察到的真实结果。
- WM 内容不可用时，P 使用独立 no-info fallback；内容可用但 confidence 不可评分时另列资格，不能伪造零分。
- 准确性参考是 D 执行 draft 后的真实第一步观察，不能用 P 改选动作后的观察。EM/token-F1 是文本匹配代理，不是完整语义真值。
- 排序使用预测 token span 的原 mean logprob；exp 分数不是校准概率。同分按冻结规则分配相同接纳概率，各指标单独报告资格、分母及原权重覆盖。

冻结描述指标与案例规则见[分析规范](../../research_progress/2026-10-10-d0-analysis/ANALYSIS_SPEC.json)。便携快照不包含完成全部来源审计所需的原始归档。

## 核心 B：同游戏整局三臂

| 策略 | 整局行为 |
|---|---|
| None | 每步执行基础 ReAct 决策 |
| no_info | 每步按固定协议增加不看预测的再决策 |
| Always | 每步按固定协议使用预测再决策；不可用预测执行既定 fallback |

每个合格 E 游戏运行三臂，单次尝试，主指标为 SR@30。主对比为 `Always − no_info`；None 相关差值为辅助对照。报告逐游戏配对差、救回/伤害、失败/缺失及 calls、tokens、时间。同接纳率不等于同成本。

这里每一步都执行所属策略，与 A 的一次干预后共同 μ 续跑不同。A、B 回答不同问题，不能互相替代。

## D0、D1、E 与待定事项

- **D0**：开发期 train 游戏。已采 24 游戏、71 点，其中 68 点有有效 D/N/P Y，3 点源 draft 失败；完整描述报告和有界 N/P 抽查尚未全部完成。见[快照](../data/d0_snapshot.json)。
- **D1**：原计划的独立局部验证池。历史使用资格、正式规模和分析方法仍需冻结；不能用于调特征、阈值或模型。
- **E**：整局 unseen 评估池。255 个资产定义不等于 255 个合格样本，历史 134 数量也不是最终 n。先核 ID、内容哈希、历史使用和资产，再固定清单、n、三臂顺序、分作业与区间规则。
- 原方案 A/B 各双侧 α=.025。任何确认性范围或额度调整必须在验证结果可见前明确，A 缩减不自动把其额度转给 B。
- **目前建议**优先准备 B，暂缓大规模 D1；A 改为 D0 探索性、NPU 主跑 E 均待双方确认，不能写成已完成的独立验证或已获准运行。
- 调用前 gate、在线 Random/Confidence、难例补采、best-of-5、第二模型属于另定范围的扩展。当前稀疏结果不能证明真实效用为零或整局 Always 无效。
