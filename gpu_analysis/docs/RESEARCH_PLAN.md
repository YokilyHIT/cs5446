## 问题与研究目标

在固定小模型 Planner 和一步 World Model 下，预测准确不一定意味着决策更好。研究要测量：预测参与决策的实际价值，是否超出了让 Planner 再思考一次的作用，以及 confidence 能否识别更值得接纳的预测。

固定 Qwen3-4B-Instruct-2507、单调用 ReAct、固定提示词和无 episodic/semantic memory。项目的基本交付是两项互补测量；Utility Gate 是有前提的方法扩展，不承诺提升。

## 原稿设计：两个核心与条件性 Gate

| 原稿目标 | 设计与贡献 |
|---|---|
| **Aim 1 / 核心 A：局部效用与 confidence** | 从 None 开发轨迹恢复同一状态，比较 D 原动作、N 无预测再决策、P 有预测再决策。当前步后统一无预测续跑，分离接纳、信息、再决策效用。在按游戏隔离的验证数据上，比较 confidence 最高半数权重与同覆盖率 Random；描述 confidence—准确性—效用关系。 |
| **Aim 2 / 条件性 Utility Gate** | 仅当标签可靠、效用存在可预测变化且资源允许，训练轻量接纳效用模型。候选输入含接纳前可见的 confidence、预测长度和动作重复；在开发集冻结特征、模型及阈值，探索性比较 confidence-only、Random，并消融 confidence。在线验证另需预算和未触碰的 unseen 游戏。 |
| **Aim 3 / 核心 B：整局成功与成本** | 不依赖 Gate 是否训练成功，在相同合格 unseen 游戏上配对比较 None、no-info、Always。主对比 Always−no_info，主指标单次尝试 SR@30；报告逐游戏不确定性、调用、tokens 和时间。 |

原稿中的接纳发生在 **WM 预测生成之后**。拒绝预测可以跳过修订，但不能节省已发生的 WM 调用。调用前 gate 属不同决策位置，必须另定可见特征与成本解释。

原稿将两个核心各按双侧 α=.025 规划；确认性信息结论须先有正向接纳证据。预算引起的范围调整应在验证结果可见前冻结，同接纳率不能被写成同成本。

## 阶段与协作原则

1. 对账旧实验及队友日志，缺材料的主张保留未核实状态。
2. 用有界开发测量检查可变性、复现性和吞吐，先确定资源上限及有意义效应的依据。
3. 在验证结果可见前，固定游戏清单、样本量、重复次数和分析方法。
4. 形成效用与整局测量，再按条件考虑 Gate 和展示材料。

原稿列出基础设施/恢复、效用标签/Gate、设计/统计、分析/写作四类工作流，并要求第二成员复核。GPU/NPU 在共享协议与日志契约下保留各自部署配置。

原稿中的准备状态和阶段日期是写作时的计划，不能当作 2026-10-15 的运行状态或完成承诺。
